# Auditorios A y B · Difusión Cultural IPN

Página estática (un solo `index.html`, sin base de datos) con el plano interactivo de los auditorios
**A “Ing. Alejo Peralta”** y **B “Ing. Manuel Moreno Torres”**:

- **Butacas:** plano con todas las butacas, búsqueda por fila y número, secciones.
- **Técnica:** cotas, corte longitudinal, niveles y equipo.
- **Audio / Iluminación:** ubicación de cada equipo según los planos de sistemas.
- **Video:** posición del proyector y área de proyección, con distancia y relación de tiro.
- **3D:** modelo three.js (`modelo-3d.html`) generado a partir de los planos, con vista desde cualquier butaca.

Para verla localmente basta con abrir `index.html` en el navegador.

> Las medidas horizontales del Auditorio B marcadas con ≈ están escaladas del plano 1:100 y deben verificarse en sitio.
